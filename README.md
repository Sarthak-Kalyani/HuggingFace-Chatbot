# AI Healthcare Assistant using Hugging Face

## Overview

This project implements an AI Healthcare Assistant using Hugging Face Transformers and Prompt Engineering techniques.

## Features

- Hugging Face Chatbot
- Prompt Engineering
- Few-Shot Prompting
- Chain of Thought Prompt Design
- Structured JSON Output
- Model Comparison
- Prompt Optimization
- Role-Based Prompting

## Technologies Used

- Python
- Google Colab
- Hugging Face Transformers
- PyTorch

## Model Used

- Qwen2.5-1.5B-Instruct
